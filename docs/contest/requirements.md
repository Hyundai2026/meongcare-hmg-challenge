## GitHub 저장소 규칙 (대회 지정)

- 소스 코드는 저장소 루트에 둔다.
- APK 경로는 `apk/<팀명>_<앱이름>_release.apk`이고, 실행 가능한 release 빌드여야 한다.
  - 용량 초과 시 GitHub Release에 첨부하고 Release URL을 제출한다.
- README.md 필수 항목:
  1. 앱 이름과 한 줄 소개
  2. 실행 방법
  3. 테스트 환경과 필요한 설정
  4. APK 위치 또는 Release 링크
- Private 저장소도 된다. "공지된 심사용 GitHub 계정"을 Collaborator로 초대하고, 마감 전에 접근되는지 확인한다.
  - **심사용 계정 ID는 2026-11-03 현재 공지되지 않았다.** 공지사항을 계속 확인한다.
  - 개인 계정의 Private 저장소는 Collaborator에게 쓰기 권한까지 준다. 초대 전에 권한을 확인한다.

## 심사 기준 (가중치 비공개)

1. **차량특화성**: 모바일이 아니라 차량이라서 생기는 가치. 주행·주차 맥락과 차량 기능을 얼마나 긴밀하게 결합했는가.
2. **창의성**: 운전자·동승자의 페인포인트를 명확히 정의하고 분명한 해결책을 제시했는가.
3. **기술 활용성**: "Pleos Playground에서 제공하는 SDK·API를 앱의 핵심 기능과 사용 경험에 적절히 활용했는가"
4. **사업성**: 타깃 고객, 유입·유지 전략 (타깃 분석, 예상 MAU, 리텐션, 확장 계획).
5. **가산점**: 시연 영상, GitHub 저장소(소스+APK).

- 네 항목은 필수 평가 항목이다. 세부 배점과 심사 과정은 공개하지 않는다.
- 2차(PT) 심사 기준은 "추후 안내 예정"이다.

## 2차 PT

- 1차 합격 20팀은 "실제 동작 가능한 앱 시연(에뮬레이터 구동 화면 또는 기기 시연)"을 **필수로** 한다. → Pleos 에뮬레이터로 시연해도 된다.
- 1차 합격팀은 PT 전까지 최종 개발 결과물을 제출해야 한다. 1차에 낸 산출물은 PT 전까지 자유롭게 고도화할 수 있다.
- 제출 결과물이 정상 구동·시연되는지 확인하고, 필요하면 보완을 요청할 수 있다.
- **PT에서 제출·시연한 결과물을 기준으로 수상작과 순위가 확정된다.** PT 뒤 추가 개발은 순위에 반영되지 않는다.
- 공지에 없는 것: 노트북 지참 여부, 현장 인터넷·Wi-Fi, 화면 출력 장비, 발표 시간.

## 기술 요구사항

- Android API 28 이상, Gradle 8.0 이상, Java 또는 Kotlin
- Pleos Connect SDK로 개발한다. 세부 내용은 [../pleos/sdk-notes.md](../pleos/sdk-notes.md) 참고.
- FAQ "어떤 SDK와 API를 쓸 수 있나요?": "Vehicle SDK, NaviHelper SDK, TextToSpeech SDK, SpeechToText SDK, FusedLocation SDK입니다."
  - Playground 콘솔에서는 이 중 TTS·STT·FusedLocation이 "준비 중"이다 ([../pleos/sdk-notes.md](../pleos/sdk-notes.md#sdk-사용-가능-상태-playground-콘솔-기준-create-project)). FAQ는 "각 SDK의 현재 제공 상태와 사용 조건은 SDK 문서 페이지에서 확인해 주세요."라고만 한다.
- 개발 가이드의 앱 예시 (주제를 제한하지 않는 참고용): "음성 메모 앱" — "SpeechToText SDK로 운전 중 음성을 받아 메모로 남깁니다." 주최측이 운전 중 음성 입력을 예시로 든다.
- 수상팀 지원 항목의 Pleos App Market 탑재는 "별도 검증·심사와 지원 차종·지역 조건을 거치며 최종 입점 또는 배포를 보장하지 않습니다."

## 출품 유의사항 (공지 "공모전 참가 및 출품 유의사항 안내")

- 출품작은 참가자의 순수 창작물이어야 한다. 표절작과 다른 공모전 기수상작은 심사에서 제외된다.
- 출품작은 제3자의 권리(초상권, 저작권, 디자인권 등)를 침해하지 않아야 한다. 분쟁 책임은 응모자에게 있다. 수상 뒤 밝혀지면 수상 취소와 상금 환수다.
  - → 앱과 기획서에 쓰는 이미지·아이콘·폰트·라이브러리의 라이선스를 확인한다.
- **제출 서류의 내용이 사실과 다르면 선정이 취소될 수 있다.**
  - → 기획서에는 확인하지 않은 Pleos 기능을 "된다"고 쓰지 않는다 (AGENTS.md 규칙 1과 같다).
- 현대자동차그룹 임직원은 참가할 수 있지만 수상 대상에서 제외된다.
- 지식재산권은 응모자에게 있다. 수상작은 다음이 적용된다.
  - 주최측이 수상 아이디어에 대한 통상실시권을 가질 수 있다 (대가·범위·기간은 협의).
  - 결과 발표일부터 4개월 동안 지식재산권 양도 등에 대한 우선협상권을 가질 수 있다.
  - 주최측은 비영리 공익 목적으로 입상작을 복제·전송할 수 있다.
- 상금은 대표 신청자에게 일괄 지급된다. 제세공과금은 원천징수된다.
- 제출 자료는 2027-02-28 뒤 폐기된다. 수상작은 2년 보관한다.

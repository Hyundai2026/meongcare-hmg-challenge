# 제휴 병원 상태 형식 (v1)

병원 웹, 차 앱, Firebase 시드가 **같이 따르는** 제휴 병원 문서 형식이다.
코드가 아니라 이 문서가 기준이다. 형식을 바꾸면 이 문서와 예시 JSON부터 고친다.

- 예시: [hospitals.sample.json](hospitals.sample.json). 시연용 가상 병원 5곳이다. 차 앱 내장 목록, 웹 메모리 저장소, 에뮬레이터 시드가 모두 이 파일과 같은 값을 쓴다. 테스트가 이 파일을 읽어서 대조한다.
- 쓰는 곳: 병원 웹 `/hospital/`(상태를 알림), 차 앱(가장 빨리 진료받을 병원 순위, 012), 시드 스크립트 `firebase/scripts/seed.mjs`.
- 계획: [docs/plans/completed/012-fastest-hospital.md](../plans/completed/012-fastest-hospital.md) "설계 결정 5"

## Firestore 경로

| 경로 | 내용 | 누가 쓰나 |
|---|---|---|
| `hospitals/{hospitalId}` | 이 문서 형식 | 병원 문서는 시드(관리자)만 만든다. 병원 웹은 `status`만 바꾼다 |
| `hospitals/{hospitalId}/staff/{uid}` | `{ "joinCode": 문자열 }`. 병원 웹 브라우저(익명 계정)를 그 병원 직원으로 등록 | 병원 웹 (코드가 맞을 때만, 보안 규칙이 확인) |
| `hospitals/{hospitalId}/cases/{caseId}` | 들어온 환자 건. [emergency-case.md](emergency-case.md) | 차 앱이 만든다 |
| `hospitalSecrets/{hospitalId}` | `{ "joinCode": 문자열 }`. 병원별 시연 코드 | 시드만. 아무도 읽지 못한다 |

- `hospitalId`는 영어 소문자·숫자·`-`다 (예: `demo-fast`).
- 병원 웹 링크: `/hospital/?h={hospitalId}&code={joinCode}`. 코드가 맞는 브라우저만 그 병원의 상태를 바꾸고 환자 카드를 읽는다 (사용자 결정 2026-11-06, 계획 012 U1).

## 필드

| 필드 | 타입 | 뜻 | 쓰는 쪽 제한 |
|---|---|---|---|
| `schemaVersion` | 숫자 | 형식 버전. 지금은 `1` | 정확히 1 |
| `name` | 문자열 | 병원 이름 | 1~40자 |
| `phone` | 문자열 또는 `null` | 전화번호 | 없으면 `null` |
| `latitude`, `longitude` | 숫자 | 좌표 (WGS84). 차 앱이 이 값으로 길안내(NaviHelper `RouteInfo`)를 요청한다 | 위도 -90~90, 경도 -180~180 |
| `address` | 문자열 또는 `null` | 주소. 지금은 화면에 보이지 않는다 | |
| `isSample` | 불리언 | 시연용 가상 병원이면 `true`. 화면에 "시연용"으로 알린다 | 시드는 모두 `true` |
| `status` | 객체 또는 `null` | 병원이 알린 상태. `null`이면 아직 알리지 않음 | 병원 웹만 바꾼다 |
| `status.waitMinutes` | 정수 | 지금 오면 예상 대기 시간(분) | 0~600 |
| `status.congestion` | `"low"`, `"normal"`, `"high"` | 혼잡도. 화면 글자는 여유 / 보통 / 혼잡 | |
| `status.acceptingEmergency` | 불리언 | 지금 응급 환자를 받는지 | |
| `status.updatedAt` | 타임스탬프 | 마지막으로 알린 시각 | 병원 웹은 서버 시각(`serverTimestamp()`)으로 쓴다. 보안 규칙이 `request.time`과 같은지 본다 |

- 타임스탬프는 Firestore timestamp다. 이 문서와 예시 JSON 같은 논리 형식에서는 ISO 8601 UTC 문자열(`2026-11-06T05:00:00Z`)로 적는다.
- **글자 수**는 유니코드 코드 포인트 수다 ([pet-profile.md](pet-profile.md)와 같다).
- `status`에 위 4개 말고 다른 키를 넣지 않는다 (보안 규칙이 막는다).

## 읽는 쪽 규칙 (차 앱, 병원 웹)

읽는 쪽은 **짐작하지 않는다.** 틀린 대기 정보로 순위를 매기는 것보다 "대기 정보 없음"으로 두는 편이 안전하다.

| 받은 것 | 결과 |
|---|---|
| `schemaVersion`이 없거나 `1`이 아님 | 그 병원을 건너뛴다 |
| `name`이 없거나 빈 문자열(공백뿐 포함) | 그 병원을 건너뛴다 |
| 좌표가 숫자가 아님, NaN·무한대, 범위 밖 | 그 병원을 건너뛴다 (길안내를 할 수 없다) |
| `phone`이 문자열이 아니거나 빈 문자열 | 전화번호 없음 ([병원에 전화]를 숨긴다) |
| `isSample`이 불리언이 아님 | `true`로 본다 (시연용이라고 알리는 쪽이 안전하다) |
| `status`가 `null`이거나 없음 | 대기 정보 없음 |
| `status`의 필드가 하나라도 없음, 타입이 틀림, `waitMinutes`가 정수가 아니거나 0~600 밖, 모르는 `congestion` | **`status` 전체를** 대기 정보 없음으로 본다 |
| 모르는 필드 | 무시하고 읽는다 |

- 숫자 필드는 정수 값으로 와도 받는다 (Firestore REST에서는 `127`이 `integerValue`로 올 수 있다).

## 오래된 정보 (차 앱의 순위 규칙)

- 지금 시각에서 `status.updatedAt`을 뺀 값이 **30분보다 크면** "대기 정보 지남"이다. 정확히 30분은 아직 유효하다.
- `updatedAt`이 지금보다 5분 넘게 뒤(시계가 어긋남)여도 "대기 정보 지남"이다. 5분 안이면 "방금"으로 본다.
- 오래된 정보의 "응급 접수 안 함"도 믿지 않는다. 대기 정보 없음과 같이 순위 뒤에 둔다.
- 순위 규칙 전체: 계획 012 "설계 결정 2" (나중에 architecture.md로 옮긴다).

## 예시 JSON (`hospitals.sample.json`)의 모양

예시 파일은 Firestore 문서 여러 개를 담는 **시드용 묶음**이다.

```json
{ "hospitals": [ { "id": "demo-fast", "seedUpdatedMinutesAgo": 2, "document": { ... } } ] }
```

- `id`: 문서 ID (`hospitals/{id}`)
- `seedUpdatedMinutesAgo`: 쓰는 쪽이 `status.updatedAt = 지금 - N분`으로 채운다. 그래서 `document.status`에는 `updatedAt`이 없다. 시드할 때마다, 차 앱 내장 목록은 받을 때마다 새로 계산한다 (Fake에서도 "정보 지난" 병원이 늘 지난 정보다).
- `document`: 위 "필드" 형식 (`status.updatedAt` 빼고)

### 시연 병원 5곳

시연 위치(Pleos 에뮬레이터 내비의 현재 위치, 37.4127212, 127.094681, 수정구 시흥동)에서 본 값이다. 좌표는 근처 역 부근이고, 이름과 전화번호는 가상이다 (실제 병원 이름을 쓰지 않는다: 출품 유의사항). 전화번호는 일반 가입 번호로 쓰이지 않는 `02-0000-000N` 형식이다.

| id | 이름 | 직선 거리 | 이동 어림 | 대기 | 혼잡 | 응급 | 알린 지 | 순위 |
|---|---|---|---|---|---|---|---|---|
| `demo-fast` | 시연용 바른 동물병원 | 5.22km | 19분 | 10분 | 보통 | 받음 | 2분 | 1위 (29분) |
| `demo-main` | 시연용 동물병원 (010 길안내 좌표) | 9.59km | 35분 | 5분 | 여유 | 받음 | 5분 | 2위 (40분) |
| `demo-near` | 시연용 가까운 동물병원 | 2.48km | 9분 | 60분 | 혼잡 | 받음 | 3분 | 3위 (69분) |
| `demo-stale` | 시연용 정보 지난 동물병원 | 8.32km | 30분 | 5분 | 여유 | 받음 | 90분 | 정보 지남 묶음 |
| `demo-closed` | 시연용 응급 휴진 동물병원 | 2.90km | 11분 | 0분 | 보통 | 안 받음 | 10분 | 응급 접수 안 함 |

- 직선 거리는 하버사인(지구 반지름 6371.0088km), 이동 어림은 `올림(km × 1.25 ÷ 21km/h × 60)`이다 (계획 012 "설계 결정 1"). 시연용 가정이다.
- "가장 가까운 곳이 가장 빠른 곳은 아니다"가 한 화면에 보이도록 짰다.
- 내비가 "너무 가깝다"는 오류를 내지 않게 모두 1.5km보다 멀리 뒀다. 좌표로 내비 경로가 나오는지는 Pleos 에뮬레이터에서 확인한다 (계획 012 관찰 O2).

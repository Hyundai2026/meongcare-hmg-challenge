## 무엇을 했나

일반 폰·태블릿(차량 기기가 아닌 곳)에서 현재 위치를 **서울 서초구 서운로 62(화면 이름 "서초동")로 고정**했다. 누가 어디서 돌려도 같은 결과가 나오고, 위치 권한을 묻지 않는다. 차량 기기(Pleos 에뮬레이터·실차)는 그대로 내비 위치를 쓴다.

## 어떻게: 핵심 결정과 이유

- **015의 기기 GPS를 뺐다** → 일반 에뮬레이터는 GPS가 없어 기본 위치(미국)를 준다. 제출 APK를 일반 에뮬레이터에서 돌리면 제휴 병원까지 "이동 약 47,080분"이 나왔다. 팀원마다 결과도 달랐다.
- **위치 표를 두 함수로**: `currentLocationKindOf`(011, 내비냐 아니냐)는 그대로 두고, 내비가 아닐 때의 값을 `fixedLocationOf`로 정한다. 011 표와 테스트를 건드리지 않는다.
- **Fake 모드는 시흥동 그대로** (U2) → 가짜 근처 병원 3곳과 테스트가 시흥동 기준이다. 서초동으로 옮기면 3곳이 5km 밖으로 빠진다.
- **제휴 시연 병원 배치는 그대로** (U1) → 폰에서는 0.9km의 "시연용 동물병원"이 1위가 된다. "가장 가까운 곳이 가장 빠른 곳은 아니다"는 Pleos 에뮬레이터(시흥동)나 카카오 근처 병원의 예시 대기로 보여 준다.
- **안내 문구에 위치 이름**: "시연용 위치(서초동) 기준이에요." (U3). Fake는 "(수정구 시흥동)".

## 사용한 Pleos SDK / API / 권한

- 새 SDK·권한 없음. **Android 위치 권한 2개(`ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION`)를 뺐다** (aapt2로 APK에서 없는 것 확인).

- `/verify`: `assembleDebug testDebugUnitTest lintDebug` 통과 (새 린트 경고 없음). 태블릿 에뮬레이터 시연 모드: 위치를 넣지 않아도 "시연용 위치(서초동) 기준이에요" + 카카오 근처 병원 (1위 ABC동물병원 약 7분), 권한 창 없음, 앱 크래시 0.

## 시연 방법

- 일반 에뮬레이터: 위치 설정 없이 `& "$HOME\meongcare-run.ps1" -NoBuild` → 시연 모드 → 진료 카드 → [가장 빨리 진료받을 곳 찾기].
- 카카오 근처 병원까지 보려면 015 노트의 Firebase 에뮬레이터 준비가 필요하다.

## 주의점 / 남은 일

- Pleos 에뮬레이터의 내비 위치는 에뮬레이터 기본값(시흥동)이다. 내비 위치를 옮길 수 있는지는 확인하지 못했다. 실차에서는 진짜 위치로 찾는다.
- 이 PC 실행 스크립트의 `-Lat/-Lon/-Here`는 이제 앱 동작에 영향이 없다 (앱이 GPS를 읽지 않는다).

## 무엇을 했나

- [증상 확인하기]를 누르면 나오는 진료 카드 화면을 확정 디자인 시안 4번 "진료 카드 확인"으로 바꿨다.
  - 카드에는 보리의 등록 정보와 고른 증상이 합쳐져 보인다.
- 처음 화면에서 진료 카드로 가는 버튼을 모두 없앴다.
- 증상 선택에서 [←]를 누르면 처음 화면으로 간다.

## 어떻게: 핵심 결정과 이유

- 카드 내용은 이전과 같다. 모양만 시안대로 바꿨다.
  - 줄: 주요 증상(강조), 기존 병력, 알레르기, 복용 약물
  - 새로 넣은 "수의사 전달" 요약 줄: 이름 · 증상 · 기존 병력
  - 반려견 줄: 품종·나이·성별
  - 아래 작은 글: "의료 진단이 아닙니다", 정보 갱신일, 시연용 표시
  - 안내 영역(013)과 전화번호 패널도 그대로다.
- 버튼은 시안대로다 (사용자 지시): [←], "● 응급 모드", [음성 명령], [동물병원 찾기]
  - [←]: 안내 전이면 증상 선택(이전 [수정]), 안내 중·도착이면 처음 화면(이전 [홈])
  - [음성 명령]은 자리만 있다. 누르면 준비 중 안내가 나온다.
  - [동물병원 찾기] 앞에 홈 [병원 찾기]와 같은 위치 아이콘을 붙였다 (사용자 요청).
  - 안내 중·도착의 [병원에 전화]·[안내 취소]·[닫기]는 이전과 같다.
  - 시안의 [자세히 보기]는 넣지 않았다. 카드에 내용이 다 보여서 연결할 기능이 없다.
- 처음 화면 (사용자 지시: "메인화면에 진료카드로 연결되는 건 다 지워라")
  - "만든 진료 카드 · 주요 증상", [카드 보기], [새로 만들기]를 없앴다.
  - [응급 진료 시작]은 늘 증상 선택으로 간다. 안내 전에 만든 카드가 있으면 새로 시작하고, 안내 중이면 고른 증상을 고친다.
  - 홈 [병원 찾기]는 카드와 상관없이 늘 시연용 병원 목록이다.
- 증상 선택 [←]·시스템 뒤로는 이전 [홈](`onGoHome`)과 같다.
  - 고르던 것은 취소하고, 만든 카드는 남긴 채 처음 화면으로 간다.
  - 이전에는 카드로 되돌아가서 카드 ↔ 증상 선택을 오갔다 (사용자 지적).
- 쓰지 않게 된 문자열 10개를 지웠다.
  - `card_edit`, `card_home`, `card_find_hospital`, `card_title_ready`, `card_subtitle_ready(_no_pet)`
  - `home_current_card_title`, `home_open_card`, `home_new_card`, `home_symptoms_line`

## 사용한 Pleos SDK / API / 권한

없음.

## 확인

- 테스트: `testDebugUnitTest` 전체 통과. 화면·이동 코드만 바꿨고 ViewModel·세션 로직은 그대로라 새 단위 테스트는 없다.
- 화면: 태블릿 에뮬레이터(시연, 라이트, 가로)에서 확인했다.
  - 증상 선택 → [증상 확인하기] → "진료 카드 확인"(고른 증상과 보리 정보, 병원 아이콘이 붙은 [동물병원 찾기])
  - [←] → 증상 선택(고른 증상이 그대로) → [←] → 처음 화면(카드 버튼 없음)
- 확인 못 함: 안내 중·도착 상태의 새 카드 모양. 시연 길안내로 출발해서 보는 확인은 하지 않았다.

## 시연 방법

1. 홈 [응급 진료 시작]을 누르고 증상을 고른 뒤 [증상 확인하기]를 누른다.
2. 진료 카드 확인 화면에서 [동물병원 찾기]를 누르거나 [←]를 누른다.

## 주의점 / 남은 일

- 처음 화면에서 만든 카드를 다시 보려면 [응급 진료 시작]으로 증상을 다시 골라야 한다. 안내 중에는 고른 증상이 남아 있다.

## 무엇을 했나

정차 중 처음 화면을 확정 디자인 시안 2번 "응급 진료"로 바꿨다. 오른쪽 바로가기 3개가 동작한다.

- **병원 찾기**: 시안 5번 화면. 시연용 가상 병원 5곳의 목록과 그린 지도가 나온다. 병원을 고르면 바로 길안내로 이어진다.
- **릴렉스**: 시안 11번 화면. 시연용 화면이고 차량에는 적용하지 않는다.
- **반려동물 카드**: 시안 12번 화면. 보기 전용이다.

## 어떻게: 핵심 결정과 이유

- 화면 크기는 폭 비율 `DesignScale`(1682dp 기준, 0.45~1.0, 버튼 최소 56dp)로 맞춘다. 시안이 차량 화면 크기 기준이라 태블릿·폰에서는 비례로 줄인다. 연결 화면(018)과 같이 쓴다.
- 아이콘은 시안 SVG 경로를 그대로 옮겼다(`HomeIcons`). 아이콘 의존성은 추가하지 않았다.
  - Material Symbols를 쓰는 안은 버렸다. 시안과 모양이 달라진다.
- 시연 샘플 반려견은 **보리 그대로**다. 왕건이로 바꾸려다 사용자가 되돌렸다.
- 시안에 없는 기능은 시안의 빈자리에 넣었다(D2).
  - [⇄ 변경] 자리 → [보호자 웹과 연결]/[연결 끊기]
  - 음성 힌트 자리 → 시연용 샘플 안내
  - "정차 중" 제목은 없앴다.
- 반려동물 카드
  - 체중·주치 병원·특징은 프로필 형식에 없어 "미등록"으로 보인다.
  - 진료 기록 칸은 "아직 진료 기록이 없어요"만 보인다. 없는 기능을 약속하지 않으려는 것이다.
  - 사진 대신 이름 첫 글자를 보인다.
- 릴렉스
  - 설정은 앱 메모리에만 있다(`RelaxViewModel`). 껐다 켜도 값은 남고, 앱을 다시 켜면 기본값이다.
  - 화면 아래에 "시연용 화면이에요. 차량 공조·음악에는 아직 적용하지 않아요."를 늘 보인다. 현재 환경 줄에는 "(예시)"를 붙였다.
- 홈 [병원 찾기] (사용자 결정)
  - 병원 데이터는 시안 이름 5곳 고정이다(`DemoHospitals`: 가상 병원, 대기시간 미확인, 카드를 받지 않음).
  - 지도는 실제 지도가 아닌 그림이고 "시연용 지도 · 가상 병원"을 늘 보인다.
  - [진료 가능 여부 문의]는 준비 중 안내만 한다.
  - 카드가 이미 있으면 지금 흐름이다: 카드와 함께 제휴 병원 목록이 열린다(D3).
  - 화면 선택: `HospitalTrip.openFinderWithoutCard()`와 `finderWithoutCard`, `parkedContentOf(finderWithoutCard)`로 고른다.
- **카카오 API는 더 쓰지 않는다.** `NEARBY_VETS_ENABLED = false`로 근처 병원 묶음을 껐다. 코드는 남겨서 되돌릴 수 있다.
- 음성은 자리만 만들었다(`ui/voice/VoiceSlots.kt`).
  - [음성 명령] 버튼은 지금 준비 중 안내만 한다.
  - "음성 안내" 멘트 줄은 화면 글자다. 나중에 TTS가 같은 글자를 읽게 한다.
- 새 정차 화면(반려동물 카드·릴렉스·병원 찾기)은 `parkedContentOf` 안에서만 고른다. 그래서 주행 중에는 `homeContentOf`가 먼저 주행 화면을 고른다(AGENTS.md 규칙 3, 바꾸지 않음).

## 시연 방법

1. `& "$HOME\meongcare-run.ps1"`을 실행한다. Firebase 서버가 꺼져 있으면 스크립트가 켜고, 시연 병원을 넣고, 미리 한 번 요청을 보내 둔다.
2. 홈 오른쪽의 바로가기를 순서대로 본다.
   - [반려동물 카드] → [←]
   - [릴렉스] → 큰 스위치를 켜고 [잔잔한 음악]을 고름 → [완료]
   - [병원 찾기] → 1번 병원 → [문의 없이 바로 이동] → [길 안내 시작]
3. [보호자 웹과 연결]을 누르면 코드가 나온다(서버가 켜져 있어야 한다).

## 주의점 / 남은 일

- 병원을 고른 뒤의 확인 화면은 아직 이전 모양이다. 시안 7번에 맞추는 일이 남았다.
- 시안의 "응답 확인" 흐름(문의 → 응답 대기 → 응답 없음 팝업)과 STT/TTS 연결이 남았다.
- 이 PC(16GB)에서는 Android 에뮬레이터와 Firebase 서버를 같이 켜면 "System UI isn't responding"이 가끔 뜬다. [Wait]나 [Close app]을 누르면 이어진다.

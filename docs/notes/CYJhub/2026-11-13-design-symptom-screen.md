## 무엇을 했나

증상 고르기 화면을 확정 디자인 시안 3번 "응급 진료 요청 · 증상 선택"으로 바꿨다. 기존 기능은 그대로 두고 모양만 바꿨다.

## 어떻게: 핵심 결정과 이유

- 사용자 지시: "지금 개발되어 있는 기능을 없애거나 바꾸지 마"
  - 그래서 `SymptomPickerScreen`의 인자와 동작은 그대로 두었다.
  - 인자는 `petName`(선택, 기본 null) 하나만 더했다.
- 기존 동작과 새 버튼의 대응

  | 시안 | 기존 동작 |
  |---|---|
  | [←] | [취소] (`onCancel`) |
  | [증상 확인하기] | [카드 만들기] (`onConfirm`) |
  | [음성으로 설명하기] | [말로 증상 고르기] (010 음성 입력 `onStart`) |
  | 듣는 중 | [듣기 취소] (`onCancel`) |
  | 들은 뒤·실패 | [다시 말하기] |

- 증상 카드: 기존 12개를 4열 × 3줄 체크 카드로 바꿨다.
  - 사용자 요청: 시안은 3×3인데, 칸을 위아래로 조금 줄여서 4×3으로. 카드 높이는 시안 128에서 104로 낮췄다.
  - 좁은 화면(840dp 미만)은 2열이다.
  - 체크 표시와 체크박스 접근성 상태는 그대로다.
- 음성 버튼 옆 안내 문구
  - 대기 중에는 "목록에 없는 증상은 말로 알려 주세요."다 (사용자가 정한 문구).
  - 듣는 중·들은 뒤·실패에는 같은 자리에 010과 같은 상태 글(알아들은 말, 고른 증상, 실패 안내)을 보인다.
  - 화면 읽기 프로그램이 바뀐 글을 읽는다(liveRegion).
- "시연용 음성 입력이에요…" 문구는 이 화면에서 뺐다 (사용자 결정 2026-11-13).
  - 음성 입력 자체(시연용 Fake 포함)는 그대로다.
- 시안의 반려동물 [변경]은 넣지 않았다. 앱은 반려견 한 마리만 다룬다.
- 제목: "{이름}가/이 지금 어떤 상태인가요?"
  - 주격 조사는 받침으로 고른다(`withSubjectParticle`).
  - 이름이 없으면 "반려동물이"다.
- 기존 부제 "진단이 아니라 수의사에게 전할 내용이에요"는 시안 부제 뒤에 남겼다.
- 쓰지 않게 된 문자열 4개(`symptoms_title`, `symptoms_subtitle`, `symptoms_confirm`, `symptoms_confirm_count`)를 지웠다.

## 사용한 Pleos SDK / API / 권한

없음. 음성 입력은 기존 010 구현을 그대로 쓴다.

## 확인

- 테스트: `KoreanParticlesTest`에 주격 조사 케이스를 더했다. `testDebugUnitTest` 전체 통과.
- 화면: 태블릿 에뮬레이터(시연, 라이트, 가로)에서 확인했다.
  - 12개가 한 화면에 들어간다.
  - 손으로 2개를 고르면 "2개 선택"이 뜨고, 카드 주요 증상도 2개다.
  - [음성으로 설명하기]를 누르면 시연 문장을 받아쓰고, 호흡 곤란·구토가 체크되고, 결과 글이 보이고, 버튼이 [다시 말하기]가 된다. [증상 확인하기]를 누르면 카드 주요 증상이 그 2개다.

## 시연 방법

1. 홈 [응급 진료 시작]을 누른다.
2. 증상 카드를 누르거나 [음성으로 설명하기]를 누른다.
3. [증상 확인하기]를 누른다.

## 주의점 / 남은 일

- 시연용 음성은 누를 때마다 다음 예시 문장을 받아쓰고, 고른 증상에 **더하기만** 한다(010의 기존 동작). 두 번 누르면 증상이 더 체크된다.
- `VoicePanel`(010의 이전 음성 영역)은 이제 화면에서 쓰지 않는다. 지우지 않고 남겨 두었다.

## 무엇을 했나

진료 카드의 [동물병원 찾기]를 누른 뒤의 흐름을 디자인 프로토타입대로 만들었다.

1. 가까운 동물병원 5곳에 진료 가능 여부를 묻고 20초를 센다.
2. 답이 오면 가장 빨리 진료받을 곳(이동 + 대기가 가장 짧은 곳)으로 출발을 제안한다.
3. 아무도 답하지 않으면 더 기다리거나, 가장 가까운 병원으로 안내하면서 전화를 연결한다.

## 어떻게: 핵심 결정과 이유 (모두 사용자 결정)

- 병원은 시안의 가상 병원 5곳이고(`DemoHospitals`), 답변은 앱 안의 시연 응답이다.
  - 응답 규칙은 순수 로직 `domain/inquiry/VetInquiry.kt`에 두었다.
  - 병원 웹과는 연결하지 않는다.
  - 화면에는 시연 표시를 하지 않는다(D1-B). 그래서 기획서·영상 자막에 반드시 적는다 (`feature-facts.md`).
- 처음부터 5곳 모두에 문의한다. 응답 대기 시간은 20초이고, 카운트다운 막대가 1초 선형 애니메이션으로 줄어든다.
- 상태 색: 진료 가능 초록, 대기 파랑, 지연 주황, 불가 빨강.
  - 답이 온 병원은 "이동 · 대기 · 총"을 파란 굵은 글씨로 보인다.
- 20초가 끝났을 때 진료 가능 답이 있으면 "○○으로 출발할까요?" 팝업이 뜬다.
  - [이 병원으로 출발 준비]를 누르면 출발 확인 화면으로 간다. 비교 경로와 같은 화면이다.
  - [다른 병원 비교]를 누르면 비교 화면으로 간다.
- 20초가 지나도 진료 가능 답이 없으면 "아직 답변한 병원이 없어요" 팝업이 뜬다.
  - [조금 더 기다리기]를 누르면 20초를 다시 센다.
  - [가장 가까운 병원으로 안내]를 누르면 진료 카드와 함께 출발하고, 동시에 전화 앱을 연다.
- 시안 병원에는 시연용 번호(02-0000-0021~0025)와 시연 ID(`demo-vet-N`)를 넣었다.
  - 카드는 앱 안 시연 전송(FakeCaseSender)이다.
- 지도는 그린 시연 지도(`DemoMap.kt`)다. 안내할 병원까지 꺾인 파란 경로를 그린다.
- debug 패널 [문의 시연: 보통/응답 없음]으로 두 팝업을 시연할 수 있다.
- 카카오 API는 쓰지 않는다. 처음 화면에서 길안내 상태 영역을 뺐다.

## 사용한 Pleos SDK / API / 권한

없음 (전화는 기존 전화 앱 열기, 길안내는 기존 `HospitalTrip.depart`).

## 확인

- 테스트
  - `VetInquiryTest`: 5곳 문의, 20초 카운트다운, 제안 병원, 가장 가까운 병원, 다시 기다리기
  - `VetInquiryViewModelTest`, `KoreanParticlesTest`(을/를·이/가·으로/로), `HospitalTripHomeFinderBoundaryTest`(시연 전송 성공)
  - 전체 통과
- 화면: 태블릿 에뮬레이터에서 확인했다.
  - 보통 시나리오: 응답 확인 → 20초 → 제안 팝업 → 출발 확인 → 길안내
  - 응답 없음 시나리오: 팝업 → [가장 가까운 병원으로 안내] → 전화 앱에 0200000021이 뜸
- 확인 못 함: tester 경계 테스트는 사용량 한도로 중단돼 이번에는 넣지 않았다. 주행 ↔ 정차를 오갈 때 같은 단계로 돌아오는지도 직접 보지 않았다.

## 시연 방법

1. `& "$HOME\\meongcare-run.ps1"`을 실행한다.
2. 홈 [응급 진료 시작] → 증상 선택 → [증상 확인하기] → [동물병원 찾기]를 누른다.
3. 20초 뒤 제안 팝업이 뜬다. debug 패널에서 "응답 없음"으로 바꾸면 응답 없음 팝업이 뜬다.

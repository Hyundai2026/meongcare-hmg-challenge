## 무엇을 했나

출발한 뒤 정차 중에 보이는 화면을 사용자가 준 디자인 "병원으로 이동 중" 그대로 만들었다. 진료 카드(안내 중 모양) 대신 이 화면이 보인다.

## 어떻게: 핵심 결정과 이유 (모두 사용자 결정)

- 화면 구조와 문구는 디자인 그대로 썼다.
  - 위쪽: 음성 안내 줄, "Pleos 내비게이션에서 길 안내 중", 병원 이름, "병원까지 N분", "오후 h:mm 도착 예정", "병원에서 ○○를 기다리고 있어요. 천천히 가도 괜찮아요."
  - 네 칸: 반려동물 / 병원에 전달 / 진료 시작 예상 / 릴렉스
  - "추가 증상 알리기"
  - 버튼: [동물병원에 전화하기] [릴렉스 모드 켜짐/꺼짐] [이동 종료] [병원 도착]
- 숫자는 줄어들지 않는다.
  - "병원까지 N분"은 출발할 때의 이동 시간이다.
  - 도착 예정은 처음 정한 시각을 그대로 둔다.
- 시연 출발·도착 자동 시나리오(`FakeTripScenario`: 출발하면 주행, 도착하면 정차)를 껐다(`TRIP_SCENARIO_ENABLED = false`).
  - 출발 뒤에도 이 화면만 남고, 큰 숫자 주행 화면이 자동으로 뜨지 않는다.
  - 시연 길안내는 주행 중에만 줄어들어서, 이제 자동 도착도 없다.
  - debug 패널 [주행]으로는 기존 주행 화면을 볼 수 있다.
- [병원 도착]은 사용자가 직접 도착 처리한다.
  - 기존 길안내 구현은 그대로 두고 감싸개 `ManualArrivalGuidanceSource`로 더했다.
  - 도착 상태를 먼저 세우고 안쪽 안내를 멈춘다. 그래서 병원 쪽에는 "취소"가 아니라 "도착"으로 간다.
  - 도착 뒤에는 기존 도착 카드 화면이 나오고, [닫기]를 누르면 홈으로 간다.
- 나머지 버튼
  - [이동 종료] = 안내 취소
  - [릴렉스 모드] = 릴렉스 화면
  - [동물병원에 전화하기] = 그 병원 번호로 전화 앱(시연 번호)
- 진료 시작 예상: 진료 가능 답이 온 병원은 "진료 시작까지 약 N분", 아니면 "대기시간 미확인"이다.
- [음성 명령]·"추가 증상 알리기"는 자리만 있다. 누르면 "음성 기능은 준비 중" 안내가 나온다.

## 사용한 Pleos SDK / API / 권한

없음.

## 확인

- 테스트: `ManualArrivalGuidanceSourceTest`(도착이 취소 없이 바로 옴, 닫기), `TripViewTest`(응답 상태, 숫자 고정). 전체 통과.
- 화면: 태블릿 에뮬레이터에서 확인했다.
  - 증상 → 카드 → 문의 → 출발 확인 → 출발 → "병원으로 이동 중"이 20초 넘게 그대로 유지됨(숫자 고정)
  - [병원 도착] → 도착 카드 → [닫기] → 홈
  - logcat에 앱 오류 없음
- 확인 못 함: 태블릿 에뮬레이터는 debug 패널 때문에 "추가 증상 알리기" 둘째 줄이 살짝 가려진다(스크롤하면 보인다). release와 차 화면에는 debug 패널이 없다.

## 주의점 / 남은 일

- 화면 문구 "Pleos 내비게이션에서 길 안내 중", "목적지를 설정했어요"는 차량 기기(내비 경로 모드)에서만 사실이다. 폰·태블릿 시연에서는 시연 길안내다. 기획서·영상에서 설명이 필요하다.
- 실제 차량(Real 길안내)에서는 주행 상태를 차가 알려 주므로 주행 중에는 기존 주행 화면이 보인다.

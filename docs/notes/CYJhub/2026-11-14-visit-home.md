## 무엇을 했나

1. 병원 도착 뒤의 흐름을 디자인 시안 그대로 만들었다: 병원 도착 → 진료 완료 → 귀가 중 → 귀가 완료.
2. 샘플 반려견 보리에 사진을 넣었다. 품종은 포메라니안, 체중·특징도 넣었다.
3. 화면의 "시연용…" 안내를 모두 뺐다.

## 어떻게: 핵심 결정과 이유 (모두 사용자 결정)

- **병원 도착** (`ui/visit/VisitScreens.kt` `ArriveScreen`)
  - 진료 카드("병원 전달 완료"), 동물병원, 진료 시작 예상, "진료 중", [차 안에서 대기]를 보인다. 아래는 [처음으로] [진료 완료]다.
  - [차 안에서 대기]를 켜면 8초 뒤 "진료 차례 · 진료실로 이동하세요"가 뜬다. 앱 안 시연이다(`VisitViewModel.callDelayMillis`).
- **진료 완료**
  - 진료 안내: 동물병원, 진료 종료 시각, 동물병원 안내 "안내 없음", 다음 진료 "미정"
  - 귀가 설정: 릴렉스 모드 스위치, [릴렉스 설정 변경]
  - "진료 안내를 반려동물 카드에 저장할까요?" [저장 안 함]/[저장]
  - 아래 버튼: [진료 안내 듣기 · 구상] [귀가 출발]
  - 저장한 기록은 앱 메모리에만 있고, 반려동물 카드 "진료 기록 N건"에 보인다.
- **귀가 중**
  - "집까지 약 N분"(병원까지 걸린 이동 시간), 릴렉스 상태, 집에서 챙길 것을 보인다.
  - 아래 버튼: [진료 안내 듣기 · 구상] [릴렉스 모드] [귀가 완료]
- **귀가 완료**
  - 오늘 진료 기록(또는 저장 안 함), 추가 안내 없음을 보인다.
  - 릴렉스를 켰으면 [편안함 기록]/[불안함 기록]이 나온다. 불안함이면 다음 이동은 조용히 + 추가 안심 안내로 바뀐다.
  - [처음으로]
- 화면 전환
  - 병원 도착은 길안내가 `Arrived`일 때 진료 카드 대신 보인다.
  - 진료 완료·귀가 중·귀가 완료는 정차 쪽 `HomePage`(AFTER_VISIT, GOING_HOME, HOME_ARRIVED)다.
  - 주행 중에는 `homeContentOf`가 먼저 주행 화면을 고른다(규칙 3).
- **보리 사진**
  - `res/drawable/sample_pet_photo.jpg`. 반려견 정보가 샘플일 때만 `PetAvatar`가 둥근 사진을 그린다(`LocalSamplePetPhoto`).
  - 품종은 포메라니안이다. 보호자 웹 예시 JSON은 골든리트리버 그대로라, 테스트는 `ExamplePetProfiles.bori`와 비교한다.
  - 체중 2.8kg, 특징 "낯선 곳에서 긴장해요, 안으면 진정해요"는 화면 표시용 상수다. 프로필 형식에는 없다.
- **시연 안내 제거**: `ui/DemoNotices.kt` `SHOW_DEMO_NOTICES = false`. 시연인 점은 `feature-facts.md`에 적었다.
- 응답 없음 → [가장 가까운 병원으로 안내]는 길안내만 한다. 자동 전화 연결은 뺐다.
- 진료 시작 예상을 모르면 시안 문구 "대기시간 미확인"을 보인다.

## 확인

- 테스트: `VisitViewModelTest`(진료 완료·차 안 대기 호출·저장/저장 안 함·이동 중 상태·화면 순서). 기존 테스트의 품종 기대값을 고쳤다. 전체 통과.
- 화면: 태블릿 에뮬레이터에서 처음부터 끝까지 확인했고, logcat에 앱 오류가 없었다.
  - 증상 → 카드 → 문의 → 출발 확인 → 이동 중 → [병원 도착]
  - 차 안 대기 → 8초 뒤 호출 → [진료 완료] → [저장] → [귀가 출발] → [귀가 완료] → [편안함 기록] → 처음으로
  - 반려동물 카드에 "진료 기록 1건"
- 확인 못 함: 전화 자동 연결을 뺀 뒤 [가장 가까운 병원으로 안내]를 다시 눌러 보지 않았다.

## 주의점 / 남은 일

- 화면에 시연 표시가 없다. 가상 병원, 시연 답변·전송·길안내·호출, 샘플 반려견 값, 릴렉스 미적용을 기획서·영상 자막에 반드시 적는다.
- "보호자 웹의 ‘진료 기록’에서 확인하세요", "다음 진료 때 동물병원에 함께 전달됩니다"는 아직 없는 기능이다.
- 보리 사진의 사용 권리를 확인한다.

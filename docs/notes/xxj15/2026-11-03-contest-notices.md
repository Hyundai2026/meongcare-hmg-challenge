## 어떻게: 핵심 결정과 이유

- **콘솔 "준비 중"은 지금 못 쓰는 것으로 본다.** → STT·TTS를 "결정"에서 "재검토(팀 논의)"로 바꿨다.
  - 이유: 문서상 "준비 중"은 "API 제공 준비 중"이라 신청 버튼이 없다. 쓸 수 있는 건 "사용 가능" 상태뿐이다.
  - 2026-11-03 팀원이 콘솔에 로그인해 직접 확인했다: STT·TTS·FusedLocation·Vehicle Control은 준비 중, Vehicle State 11개와 NaviHelper 2개는 사용 가능.
  - `ON_DEVICE`가 앱 등록 없이 동작한다는 STT 문서의 문장은 사용 허가로 보지 않는다.
- **문의를 대회 규정(A1~A5)과 Pleos 기술(B1~B4)로 나누고 우선순위를 매겼다.** 우선순위는 A1(외부 API) → B1(주행 중 사용 선언) → B2(STT 개방 시점)다. 셋 다 답에 따라 기획서가 바뀐다.
  - 공지로 답이 나온 것은 질문에서 뺐다: PT는 에뮬레이터로 시연해도 된다.
  - 새로 넣은 것: 외부 API 허용 여부, 심사용 GitHub 계정, 제출 APK 확인 환경.
- **대회 FAQ와 콘솔이 다르다는 점을 기록했다.** FAQ는 STT·TTS·FusedLocation을 "쓸 수 있는 SDK"로 들고, 개발 가이드도 "운전 중 음성 메모" 앱을 예시로 든다. 그래서 B2를 "써도 되나"가 아니라 "언제 열리나, PT 전에 열리나"로 바꿨다.
- **Gleo Interface를 조사했지만 대회에서 쓸 근거는 없다.** 대회 SDK 목록과 콘솔에 없고, 신청 자격·검토 기간·에뮬레이터 탑재 여부가 문서에 없다. 문의 B5 후보로만 둔다.
- 이전 공모전(부산모빌리티쇼 아이디어 공모전)은 우리 대회와 다른 아이디어 공모전이다. 평가 관점을 참고 자료로 남겼다: 차량 기능 연동, 지금 제공되는 기능으로 실현 가능한가.

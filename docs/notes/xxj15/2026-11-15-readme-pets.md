## 무엇을 했나

README의 화면 사진·배너·시연 GIF와 글을 시연 샘플 반려견 왕건이·오숑이(021)에 맞췄다. SDK 표에 TextToSpeech(준비 중)를 넣고, 위쪽 바로가기에 "기술 구조"를 넣었다.

## 어떻게: 핵심 결정과 이유

- 사진은 옛 사진과 같은 틀(1600×712)로 다시 찍었다. Pleos 에뮬레이터는 앱 영역 비율이 달라서(1682×1210) 쓰지 않았다.
  - Pixel 에뮬레이터에 `adb shell wm size 1600x968`, `wm density 160`을 주고, 앱 영역 y 52~764를 잘랐다 (위 상태 표시줄, 아래 debug 패널 제외). Fake 모드다.
  - 배너 시계(14:36)와 맞추려고 에뮬레이터 시계를 `adb root` 뒤 `adb shell date 111514352026.30`로 맞췄다. 그래서 출발 확인이 "오후 2:51 도착 예정"이다.
  - 문의 화면(04)은 0.3초마다 연속 캡처해 "남은 시간 2초" 장면을 골랐다.
- 합성 이미지는 틀은 그대로 두고 안쪽 화면만 바꿨다. 옛 캡처와 비교해 위치·배율을 찾았다.
  - 핵심 장면 4장: 1400×623 @ (76,76), 둥근 모서리 16
  - 정차/주행 비교 왼쪽: 1100×489 @ (76,166). 오른쪽 주행 지도 그림은 반려견이 없어 그대로
  - 배너: 1496×666 @ (1604,320). 옛 출발 확인 화면과 같은 픽셀만 바꿨다
- `10-going-home.png`(집까지 길 안내 지도 그림)는 반려견이 없어 그대로 뒀다. GIF의 귀가 중 장면은 앱 화면이다.
- 핵심 기능 4번 제목은 두 마리라 "우리 아이를"로 썼다.
- TextToSpeech는 의존성과 `TTS_SERVICE` 권한이 있지만 앱 흐름에서 소리가 나는지 확인 전이라 "준비 중"으로 적었다 (feature-facts.md 62행).

# 실행 계획

여러 단계(대략 3단계 이상)이거나 여러 세션에 걸치는 작업은 코드를 쓰기 전에 계획 파일부터 만든다.
에이전트가 세션을 새로 시작해도 이 파일만 읽으면 이어서 작업할 수 있어야 한다.

- 진행 중: `docs/plans/active/NNN-짧은-이름.md`
- 완료되면 `docs/plans/completed/`로 옮긴다.

## 템플릿

```markdown
# NNN 제목

- 목표:
- 완료 기준 (어떻게 검증하나):
- 관련 문서:

## 단계
- [ ] 1.
- [ ] 2.

## 진행 로그
- YYYY-MM-DD:

## 결정 / 배운 점
```

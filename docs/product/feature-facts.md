# 기획서에 써도 되는 것 / 아직 아닌 것

기획서 담당자용이다. 앱에서 **실제로 확인된 기능만** 기획서에 "된다"고 쓰기 위한 표다.

- 기준: 2026-11-06 dev (`c8361f6`). 기능이 바뀌면 이 표부터 고친다.
- 왜 필요한가: 공모전 출품 유의사항에 "제출 서류의 내용이 사실과 다르면 선정이 취소될 수 있다"가 있다 ([../contest/requirements.md](../contest/requirements.md)).
- "확인한 곳"의 에뮬레이터는 PC에서 돌린 Pleos 차량 에뮬레이터다. **실차에서는 아무것도 확인하지 않았다.**
- 근거는 각 개발 노트([../notes/xxj15/](../notes/xxj15/))의 "확인" 항목이다.

## 2. 조건을 붙여서 쓸 것

| 기능 | 기획서에 쓸 때 |
|---|---|
| 병원 목록 | 지금은 **시연용 가상 병원 5곳**이다. "제휴 병원이 대기 시간을 알리는 구조"로 쓰고, 실제 제휴 병원이 있다고 쓰지 않는다 |
| 이동 시간 | 병원을 비교할 때의 이동 시간은 **직선 거리로 어림한 값**이다. 출발한 뒤의 남은 시간은 내비 값이다 |
| 서버 | Firebase로 만들었지만 **PC의 Firebase 에뮬레이터에서만** 확인했다. 실제 운영 서버는 아직이다 |
| 병원에 전화 | 전화 앱을 여는 것까지다 (걸지 않는다). Pleos 에뮬레이터에서는 전화 앱이 열렸지만 번호가 보이지 않았다. 실차에서 되는지는 주최측에 문의 중이다 |
| 주행 중 사용 | 주행 중에도 앱 화면이 보이도록 선언했고 에뮬레이터에서 동작한다. 실차·앱 심사에서 허용되는지는 문의 중이다 |
| 도착 감지 | 실제 주행에서는 내비의 도착 신호를 쓰도록 만들었지만, 에뮬레이터에서는 차가 움직이지 않아 시연용 도착으로 보였다 |
| 반려견 정보 | 지금 차 앱은 **샘플 반려견 "보리"**로 카드를 만든다. 보호자 웹 연결은 아래 3번 참고 |

## 3. 쓰면 안 되는 것 (아직 없음)

| 쓰고 싶어질 문장 | 사실 |
|---|---|
| "보호자 웹에 등록한 정보가 차에 자동으로 뜬다" | **만드는 중이다 (계획 014, 2026-11-06 시작).** 끝나고 확인되면 이 표를 고친다. 그 전에는 "연결 예정"으로 쓴다 |
| "운전 중 음성으로 증상을 말한다", "음성 안내" | Pleos 음성 인식·음성 합성 SDK가 콘솔에서 "준비 중"(신청 불가)이다. 지금은 큰 버튼으로 고른다 |
| "AI가 증상을 정리해 진료 카드를 만든다" | AI를 쓰지 않는다. 등록 정보와 고른 증상을 규칙대로 합친다 |
| "주변 동물병원을 모두 검색한다" | 제휴 병원(시연 5곳)만 보인다. 일반 병원 검색은 없다 |
| "차량 실내 온도·문·창문 등 차량 데이터를 활용한다" | Pleos Vehicle SDK는 연결만 해 두고 **아무 값도 읽지 않는다** |
| "QR·링크로 진료 카드를 공유한다", "진료 이력·다음 진료 일정" | 없다 |
| "실차에서 검증했다" | 에뮬레이터에서만 확인했다 |

## 4. 기술 활용성 칸에 쓸 Pleos SDK

| SDK | 쓰는 곳 | 상태 |
|---|---|---|
| NaviHelper | 병원까지 경로 안내 시작, 현재 위치, 도착 예정 시간, 도착 신호 | 사용 중 (도착 신호는 에뮬레이터에서 확인 불가) |
| Vehicle | 연결만 | 기능 없음 |
| SpeechToText, TextToSpeech, FusedLocation | 없음 | 콘솔 "준비 중" |

- 주행·정차 판단은 Pleos SDK가 아니라 **안드로이드 자동차 표준 API**(주행 규제 신호)다. Pleos SDK로 쓰지 않는다.
- 선언한 Pleos 권한은 `NAVI_ROUTE`, `NAVI_ROUTE_SEARCH` 두 개뿐이다.

## 5. 그대로 옮겨도 되는 문장 (기획서 5번 "개발 계획")

> 운전자가 정차 중 병원을 고르고 출발하면 진료 카드가 병원 화면에 "새 환자"로 표시되고, 도착 예정 시간이 주행에 따라 갱신된다. 병원 직원이 병원 화면에서 [카드 확인]을 누르면 운전 중인 보호자의 차 화면에 "병원이 카드를 확인했어요"가 표시되어, 보호자는 병원이 준비하고 있다는 것을 운전 중에도 알 수 있다. 주행 중 화면은 큰 남은 시간과 진행 막대, 확인 한 줄만 보이고 버튼·입력·애니메이션이 없다 (AAOS 주행 규제에 맞춤). 정차하면 목적지·도착 예정 시각·병원 대기 정보·전송 상태를 보여 주고, 도착하면 "이 카드를 접수처에 보여 주세요"와 함께 진료 카드를 보인다. 새로운 Pleos 권한은 필요 없다.
